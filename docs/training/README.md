# Data Dumpster newsroom training kit

Use this kit to run a 35–40 minute newsroom session:

- `Data-Dumpster-Newsroom-Training.pptx` — a 14-slide presenter deck with speaker notes, current production screenshots, a ten-minute guided exercise, and source notes.
- `Data-Dumpster-Newsroom-Quick-Start.docx` — an eight-page desk reference covering daily use, weekly reports, the Newsroom Screen, evidence labels, and data-quality guardrails.

## Suggested session

1. Present slides 1–12 in 20–25 minutes.
2. Run the exercise on slide 13 in the live Boston News Landscape.
3. Close with slide 14 and distribute the quick-start guide.

The screenshots and interface labels were verified against production on August 7, 2026. Refresh the materials after any substantial navigation, metric, or evidence-label change.
