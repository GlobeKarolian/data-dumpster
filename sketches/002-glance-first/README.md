# Sketch 002 — Glance-first

## Design stance
Closest to the current product. Keep the at-a-glance hero metrics up top, add a horizontal signals strip below them, tighten the leaderboard into a "Market view" table with sample-floor discipline.

## Key choices
- Layout: hero metric band (divided cells) → scrolling pill strip → market table + top posts side by side → chart
- Sample-floor rows collapsed into a labeled divider inside the table instead of ranked
- Signals as compact pills, not cards — lower visual weight than variant 001

## Trade-offs
- Strong at: continuity with the current product; lowest relearning cost; dense
- Weak at: the hero band is still "numbers first" — the story is one row down
- The market table is the political-flashpoint surface; it's prominent here

## Best for
If the goal is evolution, not a redesign conversation. Everything the current page does, plus signals, minus the noise ranks.
